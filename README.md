# MBA Automated Engineering & Document Compilation Suite (IM-104C)

A Python-powered technical document compilation, vector diagram generation, and CSS Paged Media printing suite built for Computer Applications & Web Technology (`IM-104C`) at IIPS, Devi Ahilya Vishwavidyalaya, Indore.

## Key Modules
- **`generate_diagrams.py`**: Programmatically generates vector architecture schematics for MS-Access RDBMS relationships, I/O bus topologies, email protocols, search indexing flows, and mail merge workflows (`assets/`).
- **`generate_print_pdf.py`**: Compiles structured HTML + CSS Paged Media (`@page` running headers, millimeter bleed rules, automatic counters) into print-ready technical publications (`assignment_print_ready.html`, `A_IM-2K26-58_krishna_dixit.pdf`).
- **`build_assignment_docx.py`**: Builds styled Word `.docx` submissions programmatically via `python-docx` (`A_IM-2K26-58_krishna_dixit.docx`).
- **Interactive Web Forms**:
  - `student_entry_form.html` — Validated client-side student record entry interface.
  - `product_purchase_order.html` — Interactive purchase order form with live line-item totals and validation.
